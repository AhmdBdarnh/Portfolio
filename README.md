# Premium Tech Software Engineer Portfolio

A responsive, single-page React + Tailwind CSS portfolio built with Vite.

## Run locally

1. Install Node.js 20 or later.
2. In this folder, run `npm install`.
3. Run `npm start` (or `npm run dev`).
4. Open the local URL printed by Vite.

This is a Vite app, so do not start it with `node app.js`.

## Customize before publishing

- Edit `src/data.js` with your real name, bio, email, social URLs, skills, and projects.
- Replace sample project descriptions with real work and add `demo` and `repo` URLs.
- Optionally create `public/resume.pdf` and set `resume: "/resume.pdf"` in `src/data.js`.
- Update `index.html` title and description.
- Run `npm run build` to create production files in `dist/`.

## Deploy

Push this folder to GitHub and import the repository into Vercel. The build command is `npm run build`, and the output directory is `dist/`.

**Note:** The included projects and contact details are placeholders, not verified personal information.
